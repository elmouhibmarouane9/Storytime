09 · deploy

How to make it permanent

The preview link dies with this session. Three ways to make it stick, all configured in the repo.

Free · Streamlit Community Cloud

Merge the open PR, then deploy with one click. Add MIM_ACCESS_CODE in secrets. Pair it with the private Git data repo so the book survives restarts.

Open the deploy page →

Free · Hugging Face Space

Permanent https URL, private Space, same Git data backend. Walkthrough in deploy/huggingface.md.

~$7/mo · Render, Railway or Fly.io

render.yaml and fly.toml are in the repo: Docker build, a volume mounted at /app/data, secrets declared. Mount the volume — that one setting decides whether your data persists.

~€4/mo · your own server and domain

One command installs Docker, clones, generates the access code and serves HTTPS through Caddy:

curl -fsSL https://raw.githubusercontent.com/elmouhibmarouane9/Storytime/main/deploy/install.sh | bash
